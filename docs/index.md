# SI_Card_Bot command reference

- [-adversary](commands/adversary.html) - Get a single adversary panel
- [-adversaryrules](commands/adversaryrules.html) - Get adversary information specific to a given setup.
- [-aspect](commands/aspect.html) - Shows cards for a given aspect (by name or emoji).
- [-aspects](commands/aspects.html) - Lists all aspects or lists aspects for a given spirit.
- [-blight](commands/blight.html) - Blight card search
- [-board](commands/board.html) - Displays Boards
- [-card](commands/card.html) - Card Search
- [-choose](commands/choose.html) - Choose from previously found results
- [-draw](commands/draw.html) - Draw up to 10 random cards. For only taking a single card, use -take instead.
- [-dtnw](commands/dtnw.html) - Draws a days that never were. Defaults to the 6/6 DTNW if no player count is given.
- [-event](commands/event.html) - Event Search
- [-faq](commands/faq.html) - faq's website
- [-fear](commands/fear.html) - Fear card search
- [-feardeck](commands/feardeck.html) - Calculates the fear deck for a given adversary/double adversary set up.
- [-healing](commands/healing.html) - Get a healing card
- [-help](commands/help.html) - lists of commands
- [-incarna](commands/incarna.html) - Get an incarna
- [-invaderdeck](commands/invaderdeck.html) - Calculates the invader deck for a given adversary/double adversary set up.
- [-major](commands/major.html) - Major card search
- [-minor](commands/minor.html) - Minor card search
- [-power](commands/power.html) - Power Search
- [-progression](commands/progression.html) - Gets the power progression for a spirit
- [-random](commands/random.html) - Get a random spirit, single/double adversary, board or scenario
- [-reactionrole](commands/reactionrole.html) - Sets up a reaction role message!
- [-scenario](commands/scenario.html) - Gets the front or back panel for a given scenario
- [-search](commands/search.html) - search the SICK library
- [-spirit](commands/spirit.html) - Spirit Search
- [-take](commands/take.html) - Take a random card and send the SICK link. For more than 1 card, use -draw instead.
- [-unique](commands/unique.html) - Unique card search
- [-uniques](commands/uniques.html) - Gets a list of all the uniques for a spirit
