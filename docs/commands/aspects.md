# /aspects

Lists all aspects or lists aspects for a given spirit.

## Usage

```
/aspects [spirit]
```

## Options

| Option   | Type   | Required | Description                                                |
| -------- | ------ | -------- | ---------------------------------------------------------- |
| `spirit` | string | no       | Spirit whose aspects to list (blank lists every spirit's). |

Lists the Aspects available for a given spirit, with each one's emote. With no arguments, sends a paginated list of every spirit's aspects.
