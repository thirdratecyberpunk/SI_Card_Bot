# /card

Card Search

## Usage

```
/card <card>
```

## Options

| Option | Type   | Required | Description      |
| ------ | ------ | -------- | ---------------- |
| `card` | string | yes      | Power card name. |

Alias for /power - looks up a Power card by name and returns its card image link.
