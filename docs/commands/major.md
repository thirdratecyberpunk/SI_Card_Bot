# /major

Major card search

## Usage

```
/major <card>
```

## Options

| Option | Type   | Required | Description            |
| ------ | ------ | -------- | ---------------------- |
| `card` | string | yes      | Major Power card name. |

Same lookup as /power, restricted to Major Power cards.
