# -fear

Fear card search

## Usage

```
-fear [fear name]
```

Looks up a Fear card by name and returns its SICK card image link. Wrap the whole message in spoiler bars (e.g. `||-fear terrifying||`) to have the bot send the card as a blurred, click-to-reveal spoiler image.
